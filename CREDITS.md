# Image Credits

Every photograph used on this site is downloaded locally under `assets/images/` and recorded
below before being referenced from `index.html`, per the project constitution's photography
principle (`.specify/memory/constitution.md`, Principle VIII) and
`specs/001-johor-bahru-golf-travel/contracts/credits-entry-format.md`.

**Note on the four course photos (Horizon Hills, The Els Club Desaru Coast, Palm Villa,
Impian):** no freely-licensed, reuse-verified photograph of any of these four specific private
clubs' course grounds could be found on Unsplash, Pexels, Wikimedia Commons, or Flickr's
Creative Commons listings — only copyrighted photography on the clubs' own official sites and
listings. Per an explicit decision by the project owner on 2026-09-12, each course photo below
was instead sourced directly from that venue's own official website (or, for Impian, its
verified golf-industry directory listing, since it has no dedicated official site) on the
understanding that this is editorial use of the venue's own promotional imagery, not a
confirmed open reuse license. This is a documented, deliberate deviation from Principle VIII's
"only images whose reuse terms can be verified" requirement — see `plan.md`'s Complexity
Tracking table.
